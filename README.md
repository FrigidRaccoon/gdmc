# Geometry Dash in Minecraft

Geometry Dash in minecraft created without mods, datapacks, texture packs or resource packs

## Download

To download the correct version, navigate through the file system: *mainversion*/*minorversion*

The file will be named: gdmc-*majorversion*.*minorversion*-*minecraftversion*

Once you download the zip, place it in your minecraft saves folder and **unzip** it
